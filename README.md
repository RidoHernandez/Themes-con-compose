# Woof App - Material Design Customization

A simple Android application built with Jetpack Compose demonstrating how to customize Material Design themes from start to finish.

## Features

* **Custom Color Palettes:** Defined distinct color schemes for both Light and Dark themes to ensure full visual control.
* **Custom Typography:** Integrated external fonts to enhance readability and style across the app.
* **Component Shapes:** Styled UI components with customized corner shapes to guide user attention and reflect brand identity.
* **Top App Bar:** Integrated an attractive top bar to unite the screen components.

## Tech Stack

* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Design System:** Material Design 3 (`MaterialTheme`)

## What I Learned

Through this project, I learned how to customize `Theme.kt`, `Color.kt`, `Shape.kt`, and `Type.kt` files to create a cohesive design system for Android apps using modern Jetpack Compose practices.

## How to Run

1. Clone this repository.
2. Open the project in **Android Studio**.
3. Build and run the app on an emulator or physical device.
